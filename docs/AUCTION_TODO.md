## 已知限制

- 闲鱼网页端不提供拍卖出价按钮，出价必须在闲鱼 App 人工完成。
- 匿名详情接口高频调用会触发 `RGV587`，需要账号 + 代理 + 退避。
- 公开详情不返回出价次数、保证金金额、加价幅度；第 2/3 条样例连结束时间也没返回。
- 本机磁盘约 17GB 可用（96% 已用），安装浏览器/全量 Docker 构建前注意空间。
- 参考价目前只能基于在售价，成交价数据需要后续积累。
